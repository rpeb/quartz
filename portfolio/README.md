# Portfolio

Single-page techie portfolio. Edit `index.html` to customize.

## Deploy

**Option 1: GitHub Pages (separate repo)**
- Create a new repo, push this folder
- Enable GitHub Pages → deploy from main branch
- Point `quietoverflow.com` (root) to the repo via GitHub Pages custom domain

**Option 2: Cloudflare Pages**
- Connect repo or upload folder
- Deploy
- Add custom domain `quietoverflow.com`

**Option 3: Same repo, different path**
- Build output to `docs/` or a `portfolio` branch
- Configure Pages to serve from that path

## Customize

1. **Resume** — Add `resume.pdf` to this folder, or update the link
2. **Email** — Change `you@quietoverflow.com` to your email
3. **Projects** — Add/remove from the projects list
4. **About** — Edit the bio in the About section
